校园跑助手 使用说明
====================
版本 2.4.0（终版）

一、这是什么
------------
体适能/校园跑平台的电脑端辅助工具。它在电脑上完成"选学校 → 授权账号 →
爬取路线 → 更新人脸 → 开始跑步 → 查询记录"整套流程。

程序本体是作者原版的运行内核，外面加了三样增强：
  1. 路线池：17 条以上历史路线按"最久没用过"优先选，避免连续跑同一条
  2. 设备轮换：每个账号一套独立机型指纹，14 天自动换一代
  3. 上传自审：上传前算转角/均速/步数比，异常写进日志


二、安装
--------
1. 解压压缩包，进入 crun-setup 文件夹
2. 双击 crun-setup.exe
3. 选择安装位置（默认 C:\Users\<你>\AppData\Local\Programs\CRUN），点"开始安装"
4. 装完桌面会多一个"校园跑"快捷方式

注意：装新版本直接覆盖安装即可，账号和路线不会丢。
      卸载时如果勾了"同时删除数据"，本地账号、路线、人脸会一起没了。


三、第一次使用（准备页）
------------------------
按顺序点这四个：

1) 更新学校列表
   从服务器拉全部省份和学校。正常会显示"完成：26 个省份 / 329 所学校"。
   日志里能看到每个省份抓到多少所。

2) 授权登录
   选学校、填学号密码，点"授权登录"。
   ⚠ 授权前必须先在手机 App 里点"退出登录"，否则双设备在线会被平台判定违规。

3) 爬取路径
   从学校的跑步服务端把你历史跑过的路线拉下来。跑完日志显示"爬取完成"，
   路线数量从 0 变成十几条。没有路线是跑不了的。

4) 更新人脸（可选但建议）
   把你官方 App 里已上传的人脸拉到本地，跑步中途人脸验证时用。


三之补、一键准备（推荐）
------------------------
准备页顶部有一条「开跑前检查」，右边就是蓝色的【一键准备】按钮。
点它会按顺序自动做：
  ① 学校列表不足 100 所 → 自动更新
  ② 登录态 → 用 refresh_token 静默续期（不会产生新的设备登录）
  ③ 本地没有路线 → 自动爬取
  ④ 本地没有人脸 → 自动拉取
  ⑤ 最后复查一遍，逐项打 ✅ / ❌
已有的步骤会自动跳过，不会重复请求。
如果第②步续期失败，程序不会自动重登（避免踩封号红线），
会提示你手动点「登录 / 复用」。

四、跑步页
----------
- 类型：晨跑 / 自由跑 / 阳光跑（学校没开通的类型会报错，属正常）
- 距离：单位 km，比如 2.0
- 计划时间：分钟，填 0 表示程序按距离和配速自动算
- 步频：spm，填 0 表示自动
- 路线：默认"自动（最久未用）"，也可以指定某一条

点"开始跑步"后：
  ● 启动中  →  ● 跑步中（绿色，计时开始走，进度条滚动）
  →  ● 完成 或  ● 失败

失败时下面日志区会写出原因，常见的几种：
  - "没有可用的跑步路线"   → 去准备页爬取路径
  - "学校没有开通任何跑步类型" → 手机 App 里看任务是否开放
  - "Wrong password"       → 密码变了，去准备页重新授权


五、封号风险与安全登录（必读）
------------------------------
平台的两条封号红线：
  1. 同一账号短时间内出现两台设备 —— 最常见。手机 App 点"退出登录"
     只清了手机本地，服务端会话往往还活着，这时候电脑立刻登录，
     服务端看到的就是"第二台设备请求登录"。
  2. 同一台电脑先后登录多个账号 —— 会被判代跑/多号。

本版内置了三道闸（都在本地判断，不发多余请求）：
  A. 能复用就复用：本地登录态还有效时直接复用，不会再向服务器发登录请求
  B. 同账号登录间隔：15 分钟内不重复登录
  C. 换号冷却：24 小时内只能有一个账号处于登录态，切号需要二次确认
  D. 手机退出后等待：点登录会弹 300 秒倒计时，到点再发请求
     （可以"跳过等待"，但会弹确认框，风险自负）

所以要封号最少，就照这个做：
  1. 手机上完全退出登录，等 5 分钟以上
  2. 打开助手 → 准备页 → 点"登录 / 复用" → 等倒计时走完
  3. 只登一个号。要换号，等够 24 小时

三个参数可以按需调（环境变量，单位秒）：
  CRUN_LOGIN_GAP_S        同账号登录间隔，默认 900
  CRUN_SWITCH_COOLDOWN_S  换号冷却，默认 86400
  CRUN_PHONE_SETTLE_S     登录前倒计时，默认 300


五之二、账号被封 / 接口 404 怎么办（2026-11 实测）
--------------------------------------------
【禁止跑步：黑名单】
  跑步时如果返回 999 或者"系统检测到您有作弊行为已被拉入禁跑黑名单"，
  说明账号已被风控，不是程序的问题。
  - 期间「爬取路径」「更新人脸」「查询」仍然可用，只有跑步被拦
  - 不要反复重试跑步：重复请求会加重风控
  - 解封日期在报错里会写（例如 2026-12-26），到期自动恢复

【密码登录：已修复（2.6.0）】
  原版走的 /app/appstu/login 在服务器上 404 了，但 App 自己的 oauth 通道还在：
    POST <学校API>/auth/oauth/token?grant_type=password&type=app&appType=stuApp
  这版改用这条通道登录，流程是：
    ① 先用本地 token / refresh_token 把该账号所有旧会话踢掉（手机端掉线）
    ② 等 5 秒
    ③ 用账密登录，拿到全新 token
    ④ 校验新 token 是否被服务器认可
  这样服务端全程只看到一台设备，正是"先踢下线再登录"。

【历史上密码登录报 404 / 405（2.6.0 之前）】
  学校后端升级过，App 的登录接口 /app/appstu/login 在服务器上已经不存在了
  （实测 h.tsnkj.com、gdzqac.tsnkj.com、a.sxstczx.com 全部 404）。
  这版的处理方式：
  1. 优先用 refresh_token 静默续期 —— 不产生新的设备登录，最安全
  2. 续期失败再尝试密码登录（大概率 404，属服务器侧问题）
  3. 都失败就用「粘贴 token」：
     浏览器打开 https://h.tsnkj.com/?school=<你的学校代码> → 学号密码登录
     → F12 → Application → Local Storage → 复制 token / access_token
     → 回助手点「粘贴 token」→ 自动校验并写入

【准备页顶部那排 ✅/❌ 是什么】
  开跑前检查清单：学校列表、账号、登录凭据、跑步路线、人脸照片、设备指纹。
  哪一项是 ❌，右边那句就是要你做的事。

六、查询页
----------
选账号点"查询"，联网读官方记录：
  晨跑 / 阳光跑 / 自由跑 各自的有效次数，以及总有效次数、总里程、总跑步次数

如果提示"重新登录失败：Wrong password"，说明本地密码和服务器对不上，
去准备页用学号+密码重新授权一次再查。


七、数据在哪
------------
主数据：
  C:\Users\<你>\AppData\Local\CRUN\legacy\
    tsn_data.db          账号、学校、路线
    device_profiles.json 设备指纹
    face_images\         人脸图片
    logs\                日志

自动备份（每次启动都会存一份）：
  C:\Users\<你>\CRUN备份\tsn_data-latest.db
  %LOCALAPPDATA%\CRUN\legacy\tsn_data.backup-latest.db

数据目录被误删也没关系：下次启动会自动从"CRUN备份"恢复，恢复完准备页会提示。


八、卸载
--------
方法一：开始菜单 → 校园跑 → 卸载
方法二：安装目录里的 uninstall.exe
方法三：压缩包里的"卸载CRUN.exe"（独立运行，不依赖安装）

卸载时如果确认不再使用，可以勾选"同时删除数据"；
想保留账号和路线就不要勾。


九、常见问题
------------
Q: 点跑步后提示 999 或"禁跑黑名单"
A: 账号被风控了，程序无法绕过。看报错里的解封日期，期间别重复点跑步。
   其它功能（爬路径、人脸、查询）不受影响。

Q: 登录报 404 / 405，输密码没用
A: 学校的 App 登录接口已下线（不是密码错）。用准备页的「粘贴 token」，
   或先点「登录体检」看是哪一环断了。

Q: 准备页清单里「登录凭据」是 ❌
A: 说明本地没有 token。点「登录 / 复用」；如果报 404 就用「粘贴 token」。

Q: 提示 "no such table: tsn_school"
A: 数据目录被清空了。正常情况下 2.4.0 会自动恢复；如果没恢复，
   打开准备页点一次"更新学校列表"。

Q: 点跑步没反应 / 立刻变红
A: 看右下角状态和日志。最常见的是本地没有路线，去准备页爬取路径。

Q: 提示 "unable to open database file"
A: 数据目录不存在或被占用。关闭程序重开；仍不行就把
   C:\Users\<你>\CRUN备份\tsn_data-latest.db 复制到
   %LOCALAPPDATA%\CRUN\legacy\tsn_data.db。

Q: 杀毒软件报毒
A: 程序没有数字签名，PyInstaller 打包的程序常被误报，
   加白名单即可。介意的话可以只解压不安装，直接跑 crun.exe。

Q: 命令行窗口里出现 "No module named 'tsnRunServer'"，界面一直停在"启动中"
A: 2.4.0 及以前版本的缺陷：点"开始跑步"时在加载运行内核之前就去
   import 了它，导入失败后后台线程直接退出，界面状态卡住。
   2.4.1 已修复（先装载内核再导入，失败会把原因写到日志区）。
   如果你看到这句，说明还是旧版，装 2.4.1 即可。

Q: 学校列表只有广东
A: 老版本的 bug，已修复。点"更新学校列表"会拉全部省份。
